# Divergences — Star Crawler

*Pinned to Crawler-Core `9bd668a` (`VERSION`). Every Module's setting,
and every Core rule this game has knowingly departed from, with the reason. If a rule
differs from Core and is not on this page, that is a bug in this game.*

## Modules

| Module | Setting | Why |
|---|---|---|
| Leaving a melee | Core (free attack) | as ruled |
| Passive Perception | off | the surprise roll does the job, as in Mutant |
| Advantage / Disadvantage | off | never on a sheet; a blaster fight has enough modifiers |
| Treasure as XP | on | credits are the genre's reward loop: the job, the bounty, the cargo |
| Bonus actions | off | move and do one thing |
| Flanking | optional | needs a grid; the source is corridors and cantinas, not battlemaps |
| Save target (OPEN in Core) | **fixed 15**, difficulty in the modifiers | this game imports Mutant's Classes and Strains unchanged, and their 127 save-bonus traits are priced against one number; a sliding TN would reprice content this game did not write |
| Check ladder (OPEN in Core) | **7 / 9 / 11, 9 standard** | the 2d6 check is the fallback here as in Mutant: a Force power or species trait states its own x-in-6, and the general roll is for what nothing on the sheet covers |
